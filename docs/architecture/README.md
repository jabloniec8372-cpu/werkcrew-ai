## Oznaczenia statusu

- **USTALONE** — informacja wynika wprost z dotychczasowych ustaleń zapisanych w repozytorium lub z zatwierdzonego kierunku technologicznego.
- **OPEN** — decyzja nie została jeszcze podjęta. Takiego punktu nie wolno traktować jako wymagania ani uzupełniać domysłem podczas implementacji.
