# Dane demonstracyjne — DEMO

Wszystkie pliki w tym katalogu zawierają wyłącznie małe, syntetyczne dane DEMO do prezentacji i testów. Nie są to dane prawdziwych osób, klientów ani firm.

- `DEMO_workforce.json` — przykładowe kompetencje, pracownicy, dostępność, pojazdy i podstawowe stawki kosztowe.
- `DEMO_job_request.json` — niekompletny i ryzykowny scenariusz remontu łazienki.

Każdy zestaw danych wykonywalnych musi zawierać klasyfikację `DEMO_SYNTHETIC`.
Stawki i waluta są wyłącznie wartościami przykładowymi; nie stanowią reguły wyceny ani decyzji o walucie produktu.
